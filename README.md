## 📌 Overview
This repository contains Experiment 4 of the Web Development Lab curriculum:
- Demonstrating Web Content Accessibility Guidelines (WCAG 2.1 AA) principles: Perceivable, Operable, Understandable, and Robust.
- Semantic HTML5 landmark structure (`<header>`, `<nav>`, `<main>`, `<article>`, `<footer>`).
- Keyboard-accessible skip navigation link (`Skip to main content`).
- Technical SEO optimization using accurate metadata and clear heading hierarchy.
